プライバシーポリシー

勉強法、試してみた。／ yt-studio

本ポリシーは、YouTubeチャンネル「勉強法、試してみた。」（以下「当チャンネル」）および、その運営に使用するツール「yt-studio」（以下「本ツール」）における情報の取り扱いを定めるものです。

0. YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube API Services）を使用しています。本ツールを利用することにより、利用者は YouTube 利用規約 に同意したものとみなされます。Google による情報の取り扱いについては Google プライバシーポリシー をご覧ください。

1. 本ツールについて

本ツールは、当チャンネルの運営者本人のみが、自分のYouTubeチャンネルを運営するために使用する非公開のツールです。第三者に提供・販売するものではなく、運営者以外のGoogleアカウントで利用されることはありません。

2. 本ツールがアクセスする情報

本ツールは、Googleアカウントの認証（OAuth）を通じて、運営者自身のYouTubeチャンネルについてのみ、次の操作を行います。

  • 運営者が制作した動画・サムネイルのアップロードと公開予約（YouTube Data API）
  • 当チャンネルの再生数・視聴時間・視聴維持率などの統計の取得（YouTube Analytics API）
  • 当チャンネルの動画に寄せられたコメントの取得と、運営者としての返信の投稿（YouTube Data API）

3. 視聴者の皆さまの情報

当チャンネルの動画に投稿されたコメント（表示名・コメント本文・投稿日時など、YouTube上で公開されている情報）は、返信の作成とチャンネル改善のためにのみ使用します。統計情報はYouTubeが提供する集計値であり、個人を特定する情報は含まれません。

4. 情報の保存と管理

取得した情報は、運営者が管理する非公開の保存場所にのみ保存し、上記の目的以外には使用しません。

4-2. 保存期間とデータの削除

  • YouTube API から取得した統計情報・コメント情報は、取得から最長30日間保存し、それ以降は最新のデータで上書き・削除します（YouTube API サービスのデベロッパーポリシーに従います）。
  • 運営者は、Googleアカウントのセキュリティ設定から本ツールのアクセス権を取り消すことで、いつでも本ツールによるアクセスを停止できます。取り消し後7日以内に、本ツールが保存していた認証情報および取得データを削除します。
  • 視聴者の方は、ご自身のコメントの取り扱いや削除を、当チャンネルの動画へのコメントで依頼できます。依頼から7日以内に、本ツールが保存している該当データを削除します。YouTube上のコメント自体は、YouTubeの機能でいつでも削除できます。

5. 第三者への提供

取得した情報を第三者に販売・提供することはありません。ただし、返信文の下書き作成などのために、運営者が利用するAIサービスでコメント本文を処理する場合があります。

6. Google API サービスの利用について

本ツールによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。YouTubeの利用には YouTube利用規約 および Googleプライバシーポリシー が適用されます。

本ツールのアクセス権は、Googleアカウントのセキュリティ設定からいつでも取り消すことができます。

7. AIによる合成音声について

当チャンネルの動画の音声は、運営者本人の声をもとにしたAI合成音声と、キャラクターの合成音声です。

8. お問い合わせ

本ポリシーに関するお問い合わせは、当チャンネルの動画へのコメントでお寄せください。

9. 改定

本ポリシーは、必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。
