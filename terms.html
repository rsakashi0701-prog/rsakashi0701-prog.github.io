勉強法、試してみた。／ yt-studio

本規約は、YouTubeチャンネル「勉強法、試してみた。」（以下「当チャンネル」）の運営に使用するツール「yt-studio」（以下「本ツール」）の利用条件を定めるものです。

1. 適用範囲と利用者

本ツールは、当チャンネルの運営者本人のみが、自分のYouTubeチャンネルを運営する目的で利用する非公開のツールです。運営者以外の第三者に提供・販売・貸与することはありません。

2. YouTube 利用規約への同意

本ツールは YouTube API サービスを使用しています。本ツールの利用者は、YouTube 利用規約 に従うものとします。また、本ツールは YouTube API サービス利用規約 および デベロッパーポリシー を遵守して運用します。

3. 利用目的

本ツールは、次の目的にのみ使用します。

  • 運営者が制作した動画・サムネイルを、運営者自身のチャンネルにアップロードし、公開を予約すること
  • 運営者自身のチャンネルの統計情報を確認し、動画の改善に役立てること
  • 運営者自身の動画に寄せられたコメントを確認し、運営者として返信すること

4. 禁止事項

本ツールを、運営者以外のチャンネルの操作、YouTubeの各種規約・ポリシーに反する行為、スパム行為、再生数や評価の不正な操作に使用しません。

5. 情報の取り扱い

情報の取り扱いについては、プライバシーポリシー に定めるとおりとします。

6. 免責

当チャンネルの動画で紹介する勉強法・資格試験の情報は、一般的な情報提供を目的としたものであり、合格や成果を保証するものではありません。

7. 改定

本規約は、必要に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。
